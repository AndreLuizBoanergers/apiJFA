# 📖 API Bíblia Sagrada - João Ferreira de Almeida (JFA) | PHP

Uma API simples desenvolvida em **PHP puro** para consultas de capítulos e versículos da **Bíblia Sagrada - Tradução João Ferreira de Almeida (JFA)**.

---

## ✨ Funcionalidades Principais

✅ Consulta de capítulos inteiros.  
✅ Busca de versículos específicos.  
✅ Respostas no formato **JSON**.  
✅ Fácil integração com websites, aplicativos ou projetos pessoais.

---

## 🛠️ Tecnologias Utilizadas

- **PHP** (sem frameworks)
- Dados armazenados em **JSON**
- Requisições via **parâmetros GET**
